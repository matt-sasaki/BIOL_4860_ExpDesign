Goals

  • Fit and interpret random-slope models

Setup

library(tidyverse)
library(lme4)
library(lmerTest)
library(marginaleffects)

Random slopes: sleep deprivation

sleepstudy (from lme4): reaction time of 18 subjects restricted to 3 hours of sleep per night over 10 days.

ggplot(sleepstudy, aes(Days, Reaction, group = Subject)) +
  geom_line(alpha = 0.6) +
  theme_minimal()
m_int <- lmer(Reaction ~ Days + (1 | Subject), data = sleepstudy)
m_slope <- lmer(Reaction ~ Days + (1 + Days | Subject), data = sleepstudy)
anova(m_int, m_slope)

## Goals

-   Fit and interpret random-slope models
-   Distinguish nested and crossed random effects
-   Report population-level marginal effects from mixed models

## Setup

```{r}
#| label: setup
#| message: false
library(tidyverse)
library(lme4)
library(lmerTest)
library(marginaleffects)
```

## Random slopes: sleep deprivation

`sleepstudy` (from `lme4`): reaction time of 18 subjects restricted to 3 hours of sleep per night over 10 days.

```{r}
#| label: fig-sleep
#| fig-cap: "Reaction time over days of sleep restriction, by subject"
ggplot(sleepstudy, aes(Days, Reaction, group = Subject)) +
  geom_line(alpha = 0.6) +
  theme_minimal()
```

```{r}
m_int <- lmer(Reaction ~ Days + (1 | Subject), data = sleepstudy)
m_slope <- lmer(Reaction ~ Days + (1 + Days | Subject), data = sleepstudy)
anova(m_int, m_slope)
```

```{r}
summary(m_slope)
```

How much does each subject's slope vary around the average?

```{r}
VarCorr(m_slope)
```

The population-average effect, with honest uncertainty:

```{r}
avg_slopes(m_slope, variables = "Days")
```

Compare with the random-intercept-only model:

```{r}
avg_slopes(m_int, variables = "Days")
```

The estimate is the same, but the standard error grows when the model allows slopes to vary.

```{r}
predictions(m_slope, newdata = datagrid(Days = c(0, 9)), re.form = NA)
```

```{r}
#| label: fig-slope-pred
#| fig-cap: "Population-level prediction from the random-slope model"
plot_predictions(m_slope, condition = "Days", re.form = NA) +
  theme_minimal()
```
