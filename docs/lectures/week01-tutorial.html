## Your first R

```{r}

wing_length <- c(23.1, 25.4, 22.8, 26.0, 24.3)

# Basic functions
mean(wing_length)
sd(wing_length)
length(wing_length)
```

```{r}
# Indexing
wing_length[1]
wing_length[wing_length > 24]
```

## Your first plot

A small reward for getting everything installed:

```{r}
#| label: fig-first-plot
#| fig-cap: "A first look at some simulated wing lengths"
tibble(wing_length) |>
  ggplot(aes(wing_length)) +
  geom_histogram(binwidth = 1, fill = "steelblue", color = "white") +
  theme_minimal()
```
