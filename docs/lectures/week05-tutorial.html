Simulating a randomized complete block design

Suppose greenhouse bench position affects plant growth independent of treatment. A randomized block design assigns each treatment once per bench (block), so bench-to-bench variation can be separated from treatment effects.

library(tidyverse)
set.seed(1)
n_blocks <- 6
treatments <- c("Control", "Low_N", "High_N")

design <- expand_grid(block = factor(1:n_blocks), treatment = treatments)

block_effect <- rnorm(n_blocks, mean = 0, sd = 3)
names(block_effect) <- levels(design$block)

design <- design |>
  mutate(
    trt_effect = case_when(
      treatment == "Control" ~ 0,
      treatment == "Low_N"   ~ 2,
      treatment == "High_N"  ~ 5
    ),
    growth = 20 + trt_effect + block_effect[as.character(block)] +
      rnorm(n(), 0, 1.5)
  )

Compare a naive vs. blocked model

m_naive  <- aov(growth ~ treatment, data = design)
m_blocked <- aov(growth ~ treatment + block, data = design)

## Simulating a randomized complete block design

Suppose greenhouse bench position affects plant growth independent of
treatment. A randomized block design assigns each treatment once per
bench (block), so bench-to-bench variation can be separated from
treatment effects.

```{r}

library(tidyverse)
set.seed(1)
```

```{r}
#| label: simulate-rcbd
n_blocks <- 6
treatments <- c("Control", "Low_N", "High_N")

design <- expand_grid(block = factor(1:n_blocks), treatment = treatments)
```
