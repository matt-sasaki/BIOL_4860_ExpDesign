Correlation, regression, and design

ImportantObservational vs. experimental

trees is observational data — nobody assigned girth to trees. A significant regression here tells you girth and volume are associated, not that increasing girth causes more volume (though biologically we have good reason to believe a causal relationship exists in this case). Contrast this with Week 7’s tutorial, where treatment was randomly assigned — there, a significant result supports a causal claim.

## Goals

-   Distinguish correlation from regression, and both from causation
-   Fit and interpret a simple linear regression in R
-   Recognize when observational data can (and can't) stand in for an experiment

## Setup

```{r}
#| label: setup
library(tidyverse)
library(broom)
data(trees)  # built-in: girth, height, volume of felled black cherry trees
```

## Correlation

```{r}
cor(trees$Girth, trees$Volume)
cor.test(trees$Girth, trees$Volume)
```

```{r}
#| label: fig-scatter
#| fig-cap: "Tree volume vs. girth"
ggplot(trees, aes(Girth, Volume)) +
  geom_point() +
  theme_minimal()
```

## Simple linear regression

```{r}
m1 <- lm(Volume ~ Girth, data = trees)
summary(m1)
```

```{r}
tidy(m1, conf.int = TRUE)
glance(m1)
```

```{r}
#| label: fig-fit
#| fig-cap: "Linear fit of volume on girth"
ggplot(trees, aes(Girth, Volume)) +
  geom_point() +
  geom_smooth(method = "lm") +
  theme_minimal()
```

## Checking assumptions

```{r}
#| label: fig-diagnostics
#| fig-cap: "Regression diagnostics"
par(mfrow = c(2, 2))
plot(m1)
```

## Correlation, regression, and design

::: callout-important
## Observational vs. experimental

`trees` is **observational data** — nobody assigned girth to trees. A significant regression here tells you girth and volume are associated, not that increasing girth *causes* more volume (though biologically we have good reason to believe a causal relationship exists in this case). Contrast this with Week 7's tutorial, where treatment was **randomly assigned** — there, a significant result supports a causal claim.
:::

::: callout-note

:::

::: callout-note
