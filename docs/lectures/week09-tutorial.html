Week 9 Tutorial: Everything Is a Linear Model

Wednesday tutorial · reinforces Monday’s lecture

Goals

  • Reproduce familiar tests (t-tests, ANOVA, correlation) with lm()
  • See that the “different” tests are the same model with different predictors
  • Use marginaleffects to turn a fitted model into predictions, comparisons, and slopes

Setup

library(tidyverse)
library(broom)
library(marginaleffects)
Note

marginaleffects can’t use a column named group (it conflicts with its own output columns), so we rename that column in the built-in datasets below.

One-sample and paired t-tests

The built-in sleep data: extra hours of sleep for 10 patients under two drugs. Each patient appears twice (this is a paired design).

sleep2 <- sleep |> rename(drug = group)
wide <- sleep2 |> pivot_wider(names_from = drug, values_from = extra, names_prefix = "drug")
wide$diff <- wide$drug2 - wide$drug1

The classic way:

t.test(wide$drug2, wide$drug1, paired = TRUE)

    Paired t-test

data:  wide$drug2 and wide$drug1
t = 4.0621, df = 9, p-value = 0.002833
alternative hypothesis: true mean difference is not equal to 0
95 percent confidence interval:
 0.7001142 2.4598858
sample estimates:
mean difference 
           1.58

The linear model way: an intercept-only model on the differences.

m_paired <- lm(diff ~ 1, data = wide)
tidy(m_paired, conf.int = TRUE)
# A tibble: 1 x 7
  term        estimate std.error statistic p.value conf.low conf.high
  <chr>          <dbl>     <dbl>     <dbl>   <dbl>    <dbl>     <dbl>
1 (Intercept)     1.58     0.389      4.06 0.00283    0.700      2.46

Same t, same p, same confidence interval. The intercept is the mean difference.

Two groups: the two-sample t-test

pg <- PlantGrowth |> rename(treatment = group)
two <- pg |> filter(treatment %in% c("ctrl", "trt1")) |> droplevels()
t.test(weight ~ treatment, data = two, var.equal = TRUE)

data:  weight by treatment
t = 1.1913, df = 18, p-value = 0.249
alternative hypothesis: true difference in means between group ctrl and group trt1 is not equal to 0
95 percent confidence interval:
 -0.2833003  1.0253003

mean in group ctrl mean in group trt1 
             5.032              4.661 
m_two <- lm(weight ~ treatment, data = two)
tidy(m_two, conf.int = TRUE)
# A tibble: 2 x 7
  term          estimate std.error statistic  p.value conf.low conf.high
  <chr>            <dbl>     <dbl>     <dbl>    <dbl>    <dbl>     <dbl>

Checking assumptions

All of these models share assumptions about the residuals, not the raw data:

par(mfrow = c(2, 2))
plot(m_trees)
NoteExercise 3

Look at the residual plots. A tree’s volume is roughly proportional to girth² × height. What does that suggest about the straight-line fit? (We’ll fix this with multiple regression next week.)

Correlation, regression, and design

ImportantObservational vs. experimental

trees is observational — nobody assigned girth to trees. The model describes an association. In PlantGrowth, treatment was assigned, so the same kind of model supports a causal statement about treatment effects. The statistics are identical; the design differs.

## Goals

-   Reproduce familiar tests (t-tests, ANOVA, correlation) with `lm()`
-   See that the "different" tests are the same model with different predictors
-   Use `marginaleffects` to turn a fitted model into predictions, comparisons, and slopes

## Setup

```{r}
#| label: setup
#| message: false
library(tidyverse)
library(broom)
library(marginaleffects)
```

::: callout-note
`marginaleffects` can't use a column named `group` (it conflicts with its own output columns), so we rename that column in the built-in datasets below.

## One-sample and paired t-tests

The built-in `sleep` data: extra hours of sleep for 10 patients under two drugs. Each patient appears twice (this is a **paired** design).

```{r}
sleep2 <- sleep |> rename(drug = group)
wide <- sleep2 |> pivot_wider(names_from = drug, values_from = extra, names_prefix = "drug")
wide$diff <- wide$drug2 - wide$drug1
```

The classic way:

```{r}
t.test(wide$drug2, wide$drug1, paired = TRUE)
```

The linear model way: an intercept-only model on the *differences*.

```{r}
m_paired <- lm(diff ~ 1, data = wide)
tidy(m_paired, conf.int = TRUE)
```

Same t, same p, same confidence interval. The intercept **is** the mean difference.

## Two groups: the two-sample t-test

```{r}
pg <- PlantGrowth |> rename(treatment = group)
two <- pg |> filter(treatment %in% c("ctrl", "trt1")) |> droplevels()
```

```{r}
t.test(weight ~ treatment, data = two, var.equal = TRUE)
```

```{r}
m_two <- lm(weight ~ treatment, data = two)
tidy(m_two, conf.int = TRUE)
```

- `(Intercept)` = mean of the reference group (`ctrl`)
- `treatmenttrt1` = difference in means (`trt1 − ctrl`): this row **is** the t-test

### Reading the model with marginaleffects

```{r}
avg_predictions(m_two, by = "treatment")
```

```{r}
avg_comparisons(m_two, variables = "treatment")
```

`avg_predictions()` returns the group means; `avg_comparisons()` returns the difference. You didn't need to remember which coefficient meant what.

## Three groups: one-way ANOVA

```{r}
m_aov <- lm(weight ~ treatment, data = pg)
anova(m_aov)
summary(aov(weight ~ treatment, data = pg))
```

The F-test is the same. The ANOVA table asks "does *any* coefficient differ from zero?". Now ask the pairwise questions directly:

```{r}
avg_comparisons(m_aov, variables = list(treatment = "pairwise"))
```

Custom questions with `hypotheses()` — here, is the average of the two treatments different from the control?

```{r}
coef(m_aov)
hypotheses(m_aov, "(b2 + b3) / 2 = b1")
```

(`b1`, `b2`, `b3` are the coefficients in the order printed by `coef()`.)

## Two continuous variables: correlation and regression

```{r}
#| label: fig-scatter
#| fig-cap: "Tree volume vs. girth"
ggplot(trees, aes(Girth, Volume)) +
  geom_point() +
  theme_minimal()
```

```{r}
cor.test(trees$Girth, trees$Volume)
```

```{r}
m_trees <- lm(Volume ~ Girth, data = trees)
tidy(m_trees, conf.int = TRUE)
```

Standardize both variables, and the slope becomes the correlation:

```{r}
coef(lm(scale(Volume) ~ scale(Girth), data = trees))
cor(trees$Girth, trees$Volume)
```

Spearman's rank correlation is the same model on ranks:

```{r}
coef(lm(rank(Volume) ~ rank(Girth), data = trees))[2]
cor(trees$Girth, trees$Volume, method = "spearman")
```

### Predictions and slopes

```{r}
avg_slopes(m_trees, variables = "Girth")
```

```{r}
predictions(m_trees, newdata = datagrid(Girth = c(10, 14, 18)))
```

```{r}
#| label: fig-pred
#| fig-cap: "Model-predicted volume across girth, with 95% confidence band"
plot_predictions(m_trees, condition = "Girth") +
  geom_point(data = trees, aes(Girth, Volume)) +
  theme_minimal()
```

## Checking assumptions

All of these models share assumptions about the **residuals**, not the raw data:

```{r}
#| label: fig-diagnostics
#| fig-cap: "Regression diagnostics"
par(mfrow = c(2, 2))
plot(m_trees)
```
