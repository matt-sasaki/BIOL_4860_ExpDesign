Week 10 Tutorial: Multiple Regression, ANCOVA, and Interactions

Wednesday tutorial · reinforces Monday’s lecture

Goals

  • Fit models with more than one predictor (ANCOVA, interactions, two-way ANOVA)
  • Use slopes, comparisons, and predictions to interpret interactions
  • Report effects as estimates with confidence intervals

Setup

library(tidyverse)
library(marginaleffects)

Design reminder

ImportantRandomization and covariates

ANCOVA’s strength in experiments is precision: if treatment was randomly assigned, adjusting for a baseline covariate leaves the treatment estimate unbiased and shrinks its standard error. In observational data, adjustment cannot rescue a confounded design.

## Goals

-   Fit models with more than one predictor (ANCOVA, interactions, two-way ANOVA)
-   Use `slopes`, `comparisons`, and `predictions` to interpret interactions
-   Report effects as estimates with confidence intervals

## Setup

```{r}
#| label: setup
#| message: false
library(tidyverse)
library(marginaleffects)
```

## ANCOVA: groups and a covariate

Using `iris`: does sepal length differ among species after accounting for petal length?

```{r}
#| label: fig-iris
#| fig-cap: "Sepal vs. petal length by species"
ggplot(iris, aes(Petal.Length, Sepal.Length, color = Species)) +
  geom_point() +
  theme_minimal()
```

```{r}
m_anc <- lm(Sepal.Length ~ Species + Petal.Length, data = iris)
summary(m_anc)
```

The model assumes the same slope in every species. `avg_comparisons()` reports species differences *adjusted* for petal length:

```{r}
avg_comparisons(m_anc, variables = list(Species = "pairwise"))
```

## Interactions: does the slope depend on species?

```{r}
m_int <- lm(Sepal.Length ~ Petal.Length * Species, data = iris)
summary(m_int)
anova(m_anc, m_int)
```

The coefficient table is hard to read: `Petal.Length` is the slope in the *reference* species only. Ask for the slope in each species instead:

```{r}
avg_slopes(m_int, variables = "Petal.Length", by = "Species")
```

Is the slope for virginica different from versicolor?

```{r}
avg_slopes(m_int, variables = "Petal.Length", by = "Species", hypothesis = "pairwise")
```

```{r}
#| label: fig-int
#| fig-cap: "Model predictions with an interaction"
plot_predictions(m_int, condition = c("Petal.Length", "Species")) +
  theme_minimal()
```

## Two-way ANOVA: two factors

`ToothGrowth`: tooth length in guinea pigs by vitamin C supplement (`supp`) and dose.

```{r}
tg <- ToothGrowth |> mutate(dose = factor(dose))
m_tg <- lm(len ~ supp * dose, data = tg)
anova(m_tg)
```

The interaction is significant, so "the effect of supplement" depends on dose. Estimate it at **each** dose:

```{r}
avg_comparisons(m_tg, variables = "supp", by = "dose")
```

```{r}
avg_predictions(m_tg, by = c("supp", "dose"))
```

```{r}
#| label: fig-tg
#| fig-cap: "Predicted tooth length by supplement and dose"
plot_predictions(m_tg, condition = c("dose", "supp")) +
  theme_minimal()
```

Is the supplement effect at dose 0.5 different from the effect at dose 2? That's a difference of differences:

```{r}
avg_comparisons(m_tg, variables = "supp", by = "dose", hypothesis = "b1 = b3")
```

## Multiple regression with continuous predictors

```{r}
m_trees <- lm(Volume ~ Girth + Height, data = trees)
```

```{r}
avg_slopes(m_trees)
```

Compare the `Height` slope here with last week's `Volume ~ Height` model. What changed, and why?

## Design reminder

::: callout-important
## Randomization and covariates

ANCOVA's strength in experiments is **precision**: if treatment was randomly assigned, adjusting for a baseline covariate leaves the treatment estimate unbiased and shrinks its standard error. In observational data, adjustment cannot rescue a confounded design.
:::
