ANCOVA: categorical + continuous predictor

We’ll simulate a dataset where plant height depends on both a continuous covariate (starting size) and a categorical treatment — a common design in biology.

set.seed(7)
n <- 40
ancova_data <- tibble(
  treatment = rep(c("Control", "Fertilizer"), each = n / 2),
  start_height = runif(n, 5, 15),
  final_height = 2 + 1.1 * start_height +
    ifelse(treatment == "Fertilizer", 4, 0) +
    rnorm(n, 0, 1.5)
)
ggplot(ancova_data, aes(start_height, final_height, color = treatment)) +
  geom_point() +
  geom_smooth(method = "lm", se = FALSE) +
  theme_minimal()
m_ancova <- lm(final_height ~ start_height + treatment, data = ancova_data)
summary(m_ancova)

In your own words, explain what the treatment coefficient represents in this model, and why controlling for start_height matters — what would happen to your conclusions if you ignored it and just compared final_height between groups with a t-test?

Checking for an interaction

ANCOVA assumes the slopes are parallel across groups (no treatment-by-covariate interaction). Always check this.

m_interaction <- lm(final_height ~ start_height * treatment, data = ancova_data)
anova(m_ancova, m_interaction)
