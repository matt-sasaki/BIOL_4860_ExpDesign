The Wilcoxon signed-rank test is an intercept-only model on signed ranks:

signed_rank <- function(x) sign(x) * rank(abs(x))

A permutation test

Is the difference between spray C and spray A larger than expected by chance?

two <- InsectSprays |> filter(spray %in% c("A", "C")) |> droplevels()
obs <- coef(lm(count ~ spray, data = two))[2]

set.seed(14)
perm <- replicate(5000, {
  shuffled <- two
  shuffled$spray <- sample(shuffled$spray)
  coef(lm(count ~ spray, data = shuffled))[2]
})
mean(abs(perm) >= abs(obs))
[1] 0
ggplot(data.frame(perm), aes(perm)) +
  geom_histogram(bins = 40) +
  geom_vline(xintercept = obs, linetype = "dashed") +
  theme_minimal()

## A permutation test

Is the difference between spray C and spray A larger than expected by chance?

```{r}
two <- InsectSprays |> filter(spray %in% c("A", "C")) |> droplevels()
obs <- coef(lm(count ~ spray, data = two))[2]

set.seed(14)
perm <- replicate(5000, {
  shuffled <- two
  shuffled$spray <- sample(shuffled$spray)

})
mean(abs(perm) >= abs(obs))
```

```{r}
#| label: fig-perm
```
