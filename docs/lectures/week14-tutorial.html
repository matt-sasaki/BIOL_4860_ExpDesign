Setup

When parametric tests break down

Recall from Labs 4–6: t-tests, ANOVA, and regression all assume roughly normal, equal-variance residuals. When sample sizes are small and that assumption clearly fails (e.g., strongly skewed data, extreme outliers you can’t justify removing), nonparametric methods based on ranks are a safer choice.

Wilcoxon rank-sum test (nonparametric alternative to the t-test)

data(sleep)
wilcox.test(extra ~ group, data = sleep)

    Wilcoxon rank sum test with continuity correction

data:  extra by group
W = 25.5, p-value = 0.06933
alternative hypothesis: true location shift is not equal to 0

Compare to the parametric version from Week 7’s tutorial:

t.test(extra ~ group, data = sleep)

    Welch Two Sample t-test

 -3.3654832  0.2054832

The conclusions here happen to roughly agree. In general, why might a Wilcoxon test and a t-test disagree on a dataset with a small sample and a couple of extreme outliers? Which test is more sensitive to those outliers, and why?

A general-purpose backup: permutation test

When no standard nonparametric test fits your design, a permutation test lets you build a null distribution directly from your data.

set.seed(99)
observed_diff <- PlantGrowth |>
  filter(group %in% c("trt1", "trt2")) |>
  group_by(group) |>
  summarise(m = mean(weight)) |>
  summarise(diff = diff(m)) |>
  pull(diff)

perm_data <- PlantGrowth |> filter(group %in% c("trt1", "trt2"))

n_perm <- 2000
perm_diffs <- replicate(n_perm, {
  shuffled <- sample(perm_data$group)
  perm_data |>
    mutate(group = shuffled) |>
    group_by(group) |>
    summarise(m = mean(weight), .groups = "drop") |>
    summarise(diff = diff(m)) |>
    pull(diff)
})

p_value <- mean(abs(perm_diffs) >= abs(observed_diff))
p_value
[1] 0.008
tibble(diff = perm_diffs) |>
  ggplot(aes(diff)) +
  geom_histogram(bins = 40, fill = "steelblue", alpha = 0.7) +
  geom_vline(xintercept = observed_diff, color = "red", linewidth = 1) +
  labs(x = "Permuted mean difference (trt2 - trt1)",
       title = "Red line = observed difference") +
  theme_minimal()
NoteExercise 3

Compare the permutation p-value to a standard t.test() p-value on the same two groups (trt1 vs. trt2 in PlantGrowth). Are they similar? In your own words, explain what the permutation test is doing conceptually — what does “shuffling group” simulate under the null hypothesis?
