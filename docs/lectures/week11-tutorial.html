Week 11 Tutorial: Logistic Regression and GLMs

Wednesday tutorial · reinforces Monday’s lecture on generalized linear models

Goals

  • Recognize when a binary or count outcome needs something other than lm()
  • Fit and interpret a logistic regression (glm with a binomial family)
  • Get a first look at Poisson regression for count data

Setup

library(tidyverse)
library(broom)

Why not just use lm()?

A linear model fit to a 0/1 outcome can predict probabilities below 0 or above 1, and violates the constant-variance assumption near the extremes. Logistic regression models the log-odds of the outcome instead.

Logistic regression: survival example

set.seed(11)
n <- 100
seedlings <- tibble(
  light = runif(n, 0, 100),  # % canopy light
  survived = rbinom(n, 1, plogis(-3 + 0.06 * light))
)
ggplot(seedlings, aes(light, survived)) +
  geom_jitter(height = 0.05, alpha = 0.5) +
  theme_minimal()
m1 <- glm(survived ~ light, data = seedlings, family = binomial)
summary(m1)

Poisson regression: a first look at count data

set.seed(12)
counts <- tibble(
  density = runif(60, 1, 10),   # plants per m^2
  seed_count = rpois(60, lambda = exp(0.5 + 0.15 * density))
)

m2 <- glm(seed_count ~ density, data = counts, family = poisson)
summary(m2)

Fit m2 and report whether density significantly predicts seed_count. ## Why not just use `lm()`?

A linear model fit to a 0/1 outcome can predict probabilities below 0 or above 1, and violates the constant-variance assumption near the extremes. **Logistic regression** models the log-odds of the outcome instead.

## Logistic regression: survival example

```{r}
set.seed(11)
n <- 100
seedlings <- tibble(
  light = runif(n, 0, 100),  # % canopy light
```

