Week 11 Tutorial: Generalized Linear Models

Wednesday tutorial · reinforces Monday’s lecture

Goals

  • Fit logistic and Poisson regression with glm()
  • Use marginaleffects to report effects on the response scale
  • Show that the chi-square test is a log-linear model

Setup

library(tidyverse)
library(marginaleffects)

Binary data: logistic regression

Simulated seedling survival in sun vs. shade (60 seedlings each):

set.seed(11)
seedlings <- tibble(light = rep(c("Sun", "Shade"), each = 60)) |>
  mutate(light = factor(light, levels = c("Shade", "Sun")),
         survived = rbinom(n(), 1, ifelse(light == "Sun", 0.7, 0.4)))
m_log <- glm(survived ~ light, family = binomial, data = seedlings)
summary(m_log)

A continuous predictor in a GLM

Add seedling height:

seedlings$height <- round(rnorm(nrow(seedlings), 10, 2), 1)
m_log2 <- glm(survived ~ light + height, family = binomial, data = seedlings)
plot_predictions(m_log2, condition = c("height", "light")) +
  theme_minimal()

Chi-square as a linear model

A hand-built 2×2 table: germination (yes/no) with and without cold stratification.

germ <- data.frame(
  treatment = rep(c("Stratified", "Control"), each = 2),
  germinated = rep(c("Yes", "No"), times = 2),
  n = c(30, 10, 18, 22)
)
xtabs(n ~ treatment + germinated, germ)
            germinated
treatment    No Yes
  Control    22  18
  Stratified 10  30
chisq.test(xtabs(n ~ treatment + germinated, germ), correct = FALSE)

    Pearson's Chi-squared test

data:  xtabs(n ~ treatment + germinated, germ)
X-squared = 7.5, df = 1, p-value = 0.00617

The same test as a Poisson regression. The interaction asks whether the germination split depends on treatment:

m_chi <- glm(n ~ treatment * germinated, family = poisson, data = germ)
anova(m_chi, test = "Rao")

## Chi-square as a linear model

A hand-built 2×2 table: germination (yes/no) with and without cold stratification.

```{r}
germ <- data.frame(
  treatment = rep(c("Stratified", "Control"), each = 2),
  germinated = rep(c("Yes", "No"), times = 2),
  n = c(30, 10, 18, 22)
)
xtabs(n ~ treatment + germinated, germ)
```

```{r}
chisq.test(xtabs(n ~ treatment + germinated, germ), correct = FALSE)
```

The same test as a Poisson regression. The **interaction** asks whether the germination split depends on treatment:

```{r}
m_chi <- glm(n ~ treatment * germinated, family = poisson, data = germ)
anova(m_chi, test = "Rao")
```

The `Rao` score statistic for the interaction matches the chi-square.
