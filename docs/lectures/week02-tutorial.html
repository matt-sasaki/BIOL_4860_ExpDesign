Setup

library(tidyverse)

Part 1: R fundamentals

Functions and control flow

wing_length <- c(23.1, 25.4, 22.8, 26.0, 24.3)
species <- c("A", "A", "B", "B", "B")

classify_size <- function(x, threshold = 24) {
  if (x > threshold) {
    "large"
  } else {
    "small"
  }
}

sapply(wing_length, classify_size)
[1] "small" "large" "small" "large" "large"
# A simple loop (you'll rarely need this once you know vectorized ops,
# but it's worth understanding)
for (i in seq_along(wing_length)) {
  cat(species[i], "-", wing_length[i], "\n")
}

B - 24.3

Part 2: Data wrangling

Import and preview

We’ll simulate writing out and reading back a small dataset, since you won’t always start with your own .csv. In your own work, replace this with read_csv("data/your_file.csv").

Tidy data: wide → long

Most statistical models in R expect long/tidy data — one row per observation, not one row per subject with repeated-measure columns.

growth_long <- growth_wide |>
  pivot_longer(
    cols = starts_with("height_wk"),
    names_to = "week",
    names_prefix = "height_wk",
    values_to = "height"
  ) |>
  mutate(week = as.integer(week))
