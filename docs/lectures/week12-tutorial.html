Week 12 Tutorial: Mixed-Effects Models I

Wednesday tutorial · reinforces Monday’s lecture

Goals

  • Recognize non-independence in a dataset
  • Fit random-intercept models with lmer()

library(lmerTest)

Repeated measures over time

ChickWeight: weights of chicks over 21 days on different diets. Each chick is measured repeatedly. We’ll compare diets 1 and 2.

cw <- ChickWeight |>
  filter(Diet %in% c("1", "2")) |>
  mutate(Chick = factor(Chick, ordered = FALSE), Diet = droplevels(Diet))
ggplot(cw, aes(Time, weight, group = Chick, color = Diet)) +
  geom_line(alpha = 0.6) +
  theme_minimal()

Ignoring the chick structure treats ~500 measurements as independent. Instead:

m_cw <- lmer(weight ~ Time * Diet + (1 | Chick), data = cw)
summary(m_cw)

sleep2 <- sleep |> rename(drug = group)

m_pair <- lmer(extra ~ drug + (1 | ID), data = sleep2)

## Repeated measures over time

`ChickWeight`: weights of chicks over 21 days on different diets. Each chick is measured repeatedly. We'll compare diets 1 and 2.

```{r}
cw <- ChickWeight |>
  filter(Diet %in% c("1", "2")) |>
  mutate(Chick = factor(Chick, ordered = FALSE), Diet = droplevels(Diet))
```

```{r}
#| label: fig-chicks
#| fig-cap: "Individual chick growth trajectories"
ggplot(cw, aes(Time, weight, group = Chick, color = Diet)) +
  geom_line(alpha = 0.6) +
  theme_minimal()
```

Ignoring the chick structure treats ~500 measurements as independent. Instead:

```{r}
m_cw <- lmer(weight ~ Time * Diet + (1 | Chick), data = cw)
summary(m_cw)
```

Slopes within each diet (grams per day):

```{r}
avg_slopes(m_cw, variables = "Time", by = "Diet")
```

```{r}
avg_slopes(m_cw, variables = "Time", by = "Diet", hypothesis = "pairwise")
```

Population-level predictions for a "typical" chick:

```{r}
predictions(m_cw, newdata = datagrid(Time = c(0, 21), Diet = c("1", "2")), re.form = NA)
```

```{r}
#| label: fig-cw
#| fig-cap: "Population-level predicted weight by diet"
plot_predictions(m_cw, condition = c("Time", "Diet"), re.form = NA) +
  theme_minimal()
```
