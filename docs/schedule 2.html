Weekly Schedule

Spring 2027 · Mondays are lecture, Wednesdays are tutorials

Note

Mondays: lecture (slides linked below). Wednesdays: hands-on tutorial in class, which feeds directly into that week’s assignment. Data Safari exercises appear in Weeks 4, 7, 10, and 13, alongside the regular assignment.

Each assignment/Data Safari link (e.g. “PS1”) downloads the blank Quarto template (.qmd) — fill it in and render it yourself to produce your submission PDF. Tutorials and slides can be viewed with Code → View Source (top right of the page) if you’d like their .qmd source too.
